# Release Notes - Dorc Release Tools v3.5.0

## What's New

### Stream Component Logs Live
- Real-time streaming of component deployment logs during deployment
- Improved visibility into deployment progress
- Cleaner progress logging output

### Enhanced Error Handling
- Improved API error handling and reporting
- Better error messages for troubleshooting

### Full Log Retrieval
- Enhanced ability to retrieve complete component deployment logs
- Supports full audit trail of deployment activities

## Version History

### v3.5.0 (Current)
- Stream component logs live and clean up progress logging
- Implement API error handling and version bump
- Add live component progress and full log retrieval to DOrc pipeline task

### v3.4.0
- Initial release
- Basic DOrc release request functionality
- Support for TFS builds and custom URIs
- Configurable component deployment
